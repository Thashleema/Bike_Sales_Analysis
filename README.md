# 🚲 Bike Sales Data Analysis using Python, SQL, and Power BI

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow using **Python (Pandas)**, **SQL**, and **Power BI**. The objective is to analyze bike sales data, uncover business insights, and provide actionable recommendations for improving sales performance.

---

## 🎯 Objectives

* Clean and preprocess raw bike sales data.
* Store the cleaned dataset in a SQL database.
* Perform SQL-based business analysis.
* Create interactive dashboards in Power BI.
* Generate insights and recommendations for business growth.

---

## 🛠️ Technologies Used

* **Python**

  * Pandas
* **SQL**

  * Data Storage
  * Data Analysis Queries
* **Power BI**

  * Dashboard Development
  * Data Visualization

---

## 📂 Project Workflow

### 1. Data Cleaning using Pandas

* Removed duplicate records
* Handled missing values
* Standardized column names
* Corrected data types
* Validated data quality

### 2. Data Loading into SQL

* Created database tables
* Imported cleaned dataset into SQL
* Verified data integrity

## 🔍 Key Insights

* Yamaha FZ achieved the highest number of units sold.
* Royal Enfield Classic generated the highest revenue.
* Mumbai contributed the highest overall sales revenue.
* April recorded the highest monthly revenue.

---

## 💡 Business Recommendations

### 1. Increase Inventory for High-Demand Models

Maintain sufficient stock of Yamaha FZ and Royal Enfield Classic to prevent stock shortages.

### 2. Focus Marketing on Top Cities

Allocate more marketing resources to Mumbai and Delhi to maximize revenue growth.

### 3. Run Seasonal Sales Campaigns

Launch targeted promotions during high-performing months to increase sales volume.

### 4. Promote Premium Bike Segments

Encourage premium bike purchases through special offers and financing plans.
